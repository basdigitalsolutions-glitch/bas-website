# BAS Digital Solutions website

Plain static site (HTML, CSS, a little JS). No build step needed to host it.
To change text, edit the .html files, or edit `build.py` in the source package and rebuild.

Pages: EN/FR pairs for home, RFQ, Dynamics 365, customer support, three guides, checklist and privacy, plus 404.

Before publishing:
- Fill in the [brackets] in privacy.html and confidentialite.html (person responsible, date, tools, storage region, retention, analytics).
- Have the privacy text checked against Quebec's Law 25.
